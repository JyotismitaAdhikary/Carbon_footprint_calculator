## 📋 Overview

A data-driven web application that helps individuals understand, predict, and reduce their personal carbon footprint. Enter your lifestyle habits today and get a personalised 10-year emissions forecast powered by an XGBoost ML model trained on 50,000 synthetic scenarios.

---

## ✨ Features

- **📝 Personal Calculator** — Input your transport, energy, diet, and shopping habits to get an instant carbon footprint estimate
- **📊 Results Dashboard** — See your breakdown by category and compare against global benchmarks (World Average, USA, EU, Paris Agreement target)
- **🤖 ML-Powered Predictions** — XGBoost model projects your emissions 10 years into the future, accounting for feature interactions and behavioural coupling
- **💡 Personalised Recommendations** — Ranked list of actions sorted by CO₂ savings impact, with effort and cost indicators
- **🔮 Scenario Modelling** — Select recommendations and instantly see how they shift your 10-year trajectory vs business-as-usual
- **🌿 Quick Wins** — A curated list of easy everyday changes with estimated savings

---

## 🧠 How the ML Model Works

Unlike a simple formula, this app uses a trained **XGBoost regression model**:

1. **Training data** — 50,000 synthetic lifestyle scenarios are generated by randomly sampling inputs across all feature dimensions
2. **Ground truth labels** — Each scenario is labelled using physics-based emission factors (EPA, DEFRA, IPCC)
3. **Feature interactions** — XGBoost learns non-linear relationships, e.g. an electric car combined with 100% renewable energy compounds savings in ways a formula cannot capture
4. **Scenario projection** — For the 10-year forecast, input features are evolved year-by-year to reflect planned changes, and the model is re-queried at each step rather than subtracting a fixed number

The model is trained on first run and cached to disk — subsequent loads are instant.

## 🚀 Running Locally

**1. Clone the repository**
```bash
git clone https://github.com/your-username/carbon-footprint-calculator.git
cd carbon-footprint-calculator
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the app**
```bash
streamlit run app.py
```

The ML model will train automatically on first launch (~30 seconds). After that it loads instantly from cache.

---

## 🌐 Global Benchmarks Included

The app compares your footprint against: World Average, USA, EU Average, UK, Germany, France, Japan, China, India, Brazil, and the **Paris Agreement 2030 target (2.0 tons/year)**.

---

## ⚠️ Limitations

- Electricity emission intensity varies by country — the app uses a global average (0.42 kg/kWh)
- Vehicle efficiency varies by model and driving style
- The ML model is trained on synthetic data; accuracy improves with real user data over time
- Predictions are estimates, not certified carbon accounting
